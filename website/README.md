# Urugendo marketing site

Standalone landing page (not connected to the native apps).
Inspired by calm product sites like Pebla — minimal, green brand, two clear downloads.

## Local preview

Open `website/index.html` in a browser.

## Host free

Point Vercel / Netlify / GitHub Pages at the `website/` folder.

## Wire real APKs

Set `href` and `data-apk` on the two download buttons in `index.html` when APKs exist.

## Logo

Put transparent duck as `website/logo.png`.
